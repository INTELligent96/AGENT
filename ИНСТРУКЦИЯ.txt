4. SANDBOX (ОГРАНИЧЕНИЕ ПАПОК)
----------------------------------------------------------------
ЗАЧЕМ: чтобы агент не мог случайно залезть в чужие папки.

КАК РАБОТАЕТ:
- Пусто = без ограничений (агент работает со всеми папками).
- Список путей (по одному в строке) = разрешены только они и вложенные.
- Кнопка "Применить" сохраняет в config.yaml.

ПРИМЕР:
Введи:
  D:/DEEPSEEK/AGENT/TEST_FULL
  D:/Documents/Work

Теперь агент не сможет прочитать D:/Other/file.txt - ответит
"Путь вне разрешённых директорий".

ВАЖНО: Sandbox применяется во всех инструментах, включая плагины,
которые используют agent._read_safe().

----------------------------------------------------------------
5. ЛИМИТ ВРЕМЕНИ НА ЗАДАЧУ
----------------------------------------------------------------
ГДЕ: правая панель, поле с иконкой часов, кнопка "Применить".

КАК РАБОТАЕТ:
- По умолчанию 600 секунд (10 минут).
- Минимум 30 секунд.
- Сохраняется в config.yaml (agent_loop.task_timeout_seconds).
- Проверяется МЕЖДУ инструментами.

ОГРАНИЧЕНИЕ:
Если инструмент уже запущен (например, "пакетное резюме" на 50 файлов),
он доработает до конца. Таймаут не прервёт его посередине.
Это сделано специально, чтобы не портить файлы.

СОВЕТ: для дорогих операций ставь 1800 (30 минут) или 3600 (час).
Для быстрых проверок - 120-300.

9. ПЛАГИНЫ
----------------------------------------------------------------
ГДЕ: папка plugins/. Каждый .py-файл - один плагин.

КАК НАПИСАТЬ СВОЙ:
Создай plugins/my_plugin.py:

from plugins.base import BasePlugin

class MyPlugin(BasePlugin):
    name = "my_plugin"
    description = "Что делает"
    keywords = ["запусти my_plugin"]
    gui_enabled = True
    gui_button_text = "Моя кнопка"
    dangerous = False

    def execute(self, user_text, agent):
        path = agent._extract_path_from_text(user_text)
        if not path:
            return "Укажи файл."
        text = agent._read_safe(path)
        return "Длина: " + str(len(text))

Перезапусти агент - плагин появится в GUI и в чате.

ЧТО ДОСТУПНО:
- agent.registry.generate_with_fallback(task, prompt) - вызов LLM
- agent._read_safe(path) - безопасное чтение файла
- agent._extract_path_from_text(text) - путь из текста
- agent.output_dir - папка результатов
- agent.config - конфиг

ПРИМЕР ПЛАГИНА: plugins/word_count.py (статистика по документу).

11. КРИТИК (САМОПРОВЕРКА)
----------------------------------------------------------------
Два тумблера в левой панели:
- "Включить критика" - главный выключатель.
- "Всегда (даже для кода)" - проверять даже код и веб-поиск.

ЛОГИКА:
- После ответа агента запускается вторая модель-критик.
- Оценивает ответ по шкале 1-10.
- Если score < 7 или verdict=retry - ответ уходит обратно в LLM.
- Повтор до 2 раз. Если всё ещё плохо - возвращает лучший вариант
  с пометкой "[Критик: качество ниже нормы...]".

ДЛЯ RAG: критик использует factual-check (проверяет, все ли
конкретные факты в ответе подтверждаются контекстом).

НАСТРОЙКА в config.yaml:
  self_check:
    enabled: true
    force_always: false
    max_retries: 2
    min_score: 7

СКОРОСТЬ:
- enabled=false - максимально быстро.
- enabled=true, force=false - сбалансированно.
- enabled=true, force=true - строго, но медленнее.

----------------------------------------------------------------
12. WORD СТУДИЯ
----------------------------------------------------------------
Кнопка "Студия стилей Word". Отдельное окно с 4 вкладками:
1. ИИ-соответствие - LLM сопоставит стили.
2. Безопасная замена - жёсткие правила (Heading 1 -> Заголовок 1).
3. Ручное - сам выбираешь стили из списков.
4. Нумерация - добавит "Таблица N" и "Рисунок N" для объектов без номеров.

Оригинал НИКОГДА не меняется. Результаты - в output/AI_STYLED_*,
SAFE_STYLED_*, MANUAL_STYLED_*, CAPTIONED_*.

14. ЧАСТЫЕ ПРОБЛЕМЫ
----------------------------------------------------------------
500 Server Error:
  Модель упала (OOM или context). Увеличь Context Length в LM Studio
  (>= 4096). Агент сам попробует уменьшить max_tokens и переключиться.

Модель не найдена:
  Имя в config.yaml не совпадает с LM Studio. Скопируй точное имя
  из вкладки Local Server.

RAG не находит ответ:
  1. Нажми "Сбросить базу RAG" и переиндексируй папку.
  2. Проверь, что папка действительно была проиндексирована.
  3. В логах [RAG] Источники видно, откуда взяты чанки.
     Если нужного файла нет - значит, эмбеддинги не нашли.
     Можно увеличить top_k в rag/qa.py.

Ошибка "Путь вне разрешённых директорий":
  Ты настроил Sandbox. Добавь нужную папку в поле разрешённых
  директорий или очисти список.

Чат не копируется:
  Кнопка "Копировать чат" в правой панели. Или автосохранение
  в output/chat_*.txt при закрытии.

Ctrl+V не работает в поле ввода:
  После каждого ответа фокус автоматически возвращается в поле.
  Если нет - кликни по полю ввода.

Медленно работает:
  1. Отключи критика (тумблер).
  2. Используй 7B модели для простых задач.
  3. Уменьши max_iterations для кода.

1. Быстрый старт

  1. Установи библиотеки: pip install -r requirements.txt
  2. Установи Tesseract OCR (языки rus + eng).
  3. LM Studio: загрузи модели, запусти Local Server на порту 1235.
  4. Проверь config.yaml — имена моделей должны совпадать.
  5. Запусти: python main.py

2. Sandbox — ограничение папок

Правая панель, блок «🔒 Разрешённые директории».

  • Пусто = агент работает со всеми папками.
  • Список путей (по одному на строку) = разрешены только они и вложенные.
  • Кнопка «Применить» сохраняет в config.yaml.
Пример: введи
D:/DEEPSEEK/AGENT/TEST_FULL
D:/Documents/Work
Теперь агент не сможет прочитать D:/Other/file.txt — ответит «Путь вне разрешённых директорий».

3. Лимит времени

Правая панель, поле «⏱ Лимит времени на задачу (сек)» + кнопка «Применить».

  • По умолчанию 600 секунд (10 минут).
  • Минимум 30. Сохраняется в config.yaml.
  • Проверяется между инструментами.
Важно: если инструмент уже запущен (например, «пакетное резюме» на 50 файлов), он доработает до конца — таймаут не прервёт его посередине. Это сделано для безопасности файлов.

4. История диалога

Агент помнит последние 5 пар вопрос-ответ. Это позволяет:

  • Спрашивать «а кто директор?» после «что в папке X?»
  • Уточнять: «а ещё что-нибудь про это есть?»
Пример:
Вы: что в папке D:/Docs? в каком году основана компания?
Агент: 1995 (doc1.txt)
Вы: а кто директор?
Агент: Иван Иванов (doc1.txt) ← помнит контекст

5. Диалог «Укажите папку»

Если запрос требует путь, а ты его не указал — агент спросит.

Вы: сделай список файлов
Агент: Укажите папку. Напишите путь следующим сообщением.
Вы: D:/DEEPSEEK/AGENT/TEST_FULL
Агент: (выполняет make_file_list)

6. Копирование/сохранение чата

  • Кнопка «Копировать чат» — весь текст в буфер обмена.
  • Кнопка «Сохранить чат в файл» — output/chat_YYYYMMDD_HHMMSS.txt.
  • При закрытии окна — автосохранение.

Все логи доступны в папке output/, файлы chat_*.txt. И в PyCharm (полные print()-логи).

7. Плагины

Папка plugins/. Каждый .py — один плагин.

from plugins.base import BasePlugin

class MyPlugin(BasePlugin):
    name = "my_plugin"
    description = "Что делает"
    keywords = ["запусти my_plugin"]
    gui_enabled = True
    gui_button_text = "Моя кнопка"
    dangerous = False

    def execute(self, user_text, agent):
        path = agent._extract_path_from_text(user_text)
        if not path:
            return "Укажи файл."
        text = agent._read_safe(path)
        return "Длина: " + str(len(text))

Перезапусти агент — плагин появится в GUI и в чате.

8. Сброс базы RAG

Кнопка «Сбросить базу RAG» в левой панели (красная).

Когда нужно:

  • В базе мусор от старых индексаций (видно по [RAG] Источники в логах).
  • Сменил embedding-модель.
  • RAG отвечает плохо.

После сброса: заново проиндексируй папку.

9. Критик

Два тумблера в левой панели: «Включить критика» и «Всегда (даже для кода)».

РежимЧто делает
enabled=falseКритика нет, максимальная скорость
enabled=true, force=falseТолько для смысловых задач (RAG, резюме, перевод)
enabled=true, force=trueДля всего, включая код. Максимально строго

Для RAG используется factual-check (проверка по контексту).

Порог accept: score >= 7. Настраивается в config.yaml.

10. Word Студия

Кнопка «Студия стилей Word». Отдельное окно с 4 вкладками:

  • ИИ-соответствие — LLM сопоставит стили
  • Безопасная замена — жёсткие правила (Heading 1 → Заголовок 1)
  • Ручное — сам выбираешь стили из списков
  • Нумерация — добавит «Таблица N» и «Рисунок N» для объектов без номеров

Оригинал никогда не меняется. Результаты в output/.

11. API-модели

Кнопка «Добавить LLM (API)» в настройках.

Заполни: название, Base URL, API Key, имя модели. Сними галочку «Локальная» для внешних сервисов.

Роутер автоматически ставит API-модель второй в цепочке fallback. Перезапусти приложение после добавления.

1. Что это и зачем

Локальный ИИ-агент для работы с документами Word, Excel, PDF и картинками.

  • Поиск по локальным документам (RAG).
  • Суммаризация, проверка орфографии, написание кода.
  • Создание документов Word с сохранением ваших стилей.
  • Автоматическая нумерация таблиц и рисунков.
  • Сортировка файлов, графики в Excel, веб-поиск.

3. Установка с нуля

Внимание: Установите все библиотеки через pip install, а также Tesseract OCR и LM Studio. 
pip install customtkinter python-docx openpyxl PyMuPDF pytesseract Pillow docxtpl xlrd pandas pywin32 chromadb sentence-transformers lxml ddgs xlsxwriter requests pyyaml

Путь к Tesseract прописывается в config.yaml в блоке tools.

5. Интерфейс

Левая панель: кнопки инструментов, тумблеры критика, настройки API.

Правая панель: чат для общения с агентом на естественном языке (например: "сделай резюме D:/Docs/report.docx").

6. Роутер и Критик

Роутер — понимает ваши команды. Ищет ключевые слова (например, "напиши код"), если не находит — спрашивает LLM.

Критик — проверяет ответы ИИ. Оценивает по шкале 1-10. Если оценка ниже 8, заставляет ИИ переписать ответ. Включается галочками в меню.

7. Word Студия

Кнопка «Студия стилей Word». Позволяет:

  • Автоматически перенести ваши стили из шаблона в документ.
  • Сопоставить стили через ИИ.
  • Добавить нумерацию "Таблица 1", "Рисунок 1" для тех объектов, у которых нет названий.
